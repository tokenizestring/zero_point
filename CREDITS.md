# Credits

Zero Point uses a small set of free third-party assets next to the ones made for the game. Thank you to everyone who shares their work.

| Asset | Source | Licence |
|---|---|---|
| Scanned texture sets in `assets/raw/textures`, several rock, plant and prop models in `assets/raw/models`, and the sky images in `assets/raw/hdri` | [Poly Haven](https://polyhaven.com) | CC0 |
| Texture sets in `assets/raw/textures_acg` | [ambientCG](https://ambientcg.com) | CC0 |
| Character meshes, skeletons and animation clips in `assets/raw/characters` and `assets/raw/animations` | [Microsoft Rocketbox Avatar Library](https://github.com/microsoft/Microsoft-Rocketbox) | MIT, see `assets/raw/characters/LICENSE_rocketbox.md` |
| Impact, interface and RPG sound packs in `assets/source/audio/kenney_*` | [Kenney](https://kenney.nl) | CC0 |
| Gunshot, reload, creature, forest and cricket sounds in `assets/source/audio/oga_*` | [OpenGameArt.org](https://opengameart.org) | CC0 |
| Kalam typeface | Indian Type Foundry | SIL Open Font License, see `assets/source/fonts/OFL_kalam.txt` |
| IM Fell English typeface | Igino Marini | SIL Open Font License, see `assets/source/fonts/OFL_imfell.txt` |

The download list for the Poly Haven files is kept in `assets/raw/downloads.tsv`.

Everything else (the code, the terrain, guns, trees, grass, buildings, the train, synthesized sounds and the interface art) was made for this project.
